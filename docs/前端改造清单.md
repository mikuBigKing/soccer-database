# 前端改造清单（邮箱认证 + 管理端补全）

> 前端仓库不在当前工作区，以下以「TypeScript + 常见 SPA（Vue/React 均可）」为假设，路径名按项目实际结构调整。
> 后端契约见：`docs/邮箱认证接口契约.md`、`docs/管理端与遴选接口契约.md`。

|---|---|---|

| P2 | 遴选档案 / 评分 / 最佳球员 | 管理端页面 + 前台展示接口替换 |

## 二、通用层改造

1. `api/auth.ts`
   - `login({ email, password })` 替换原 `phone`
   - `register({ name, email, code, password, role })`
   - 新增 `sendEmailCode({ email, scene })`
   - 新增 `resetPassword({ email, code, new_password })`
   - 新增 `changePassword({ old_password, new_password, code })`
   - 新增 `changeEmail({ email, code })`
   - 删除所有以 `phone` 作为登录参数的调用
2. `types/auth.ts`
   - `LoginPayload` 改为 `email`
   - 新增 `EmailScene = 'register' | 'reset_password' | 'change_password' | 'change_email'`
   - 新增 `VerificationCodeResponse = { expires_in: number; cooldown: number }`
3. 错误处理
   - `10001`：参数错误 / 验证码错误或过期（后端在 `msg` 中给出具体文案，直接展示）
   - `40001`：发送过于频繁（展示 `msg`，按钮恢复倒计时）
   - `20002/20003`：账号不存在或已禁用
   - 登录页不再出现"手机号不存在"，统一为"邮箱或密码错误"
4. 登录态
   - `localStorage` 中若存有旧版用户信息（含 phone 作为账号），登录后覆盖
   - 路由守卫按 `role` 分流不变；管理员登录仍走 `/api/admin/auth/login`
5. 通用组件（建议抽一个）
   - `EmailCodeButton`：60 秒倒计时、loading、错误恢复、`scene` 参数
   - `EmailField`：去空格、小写、格式校验
   - `PasswordField`：最少 6 位、二次确认

## 三、页面级清单

### P0 认证

| 页面 | 改动 | 验收点 |
|---|---|---|
| 登录页 | 手机号输入框 → 邮箱；"忘记密码"入口；移除手机号相关文案 | 邮箱+密码可登录；旧手机号登录被拒 |

## 四、接口对接速查

```
POST /api/auth/email/send          {email, scene}              -> {expires_in, cooldown}

POST /api/auth/login               {email, password}
POST /api/auth/password            {old_password, new_password, code}
POST /api/auth/password/reset      {email, code, new_password}
POST /api/auth/email/change        {email, code}
GET  /api/auth/me

```

管理员端新增接口见 `docs/管理端与遴选接口契约.md`，字段无需二次转换。

## 五、交互与文案规范

- 验证码按钮：点击后立即禁用并显示 `60s` 倒计时，失败（40001）时恢复按钮并提示服务端 `msg`
- 验证码输入：6 位数字，输入完成可自动聚焦提交按钮
- 邮件提示：发送成功后提示「验证码已发送，请检查收件箱与垃圾邮件」
- 占位邮箱：任何改密/找回入口都提示「当前账号未绑定可用邮箱，请联系管理员补录」
- 错误展示：直接使用后端 `msg`，不要前端自行改写，避免与后端规则不一致

## 六、回归与验收用例

1. 新邮箱注册 → 登录 → 改密（旧密码 + 验证码）→ 新密码登录
2. 忘记密码全流程；错误验证码、过期验证码、连续错误 5 次
3. 同一邮箱 60 秒内重复发送被拒（40001）
4. 换绑邮箱后用新邮箱登录，旧邮箱登录失败
5. 占位邮箱账号改密被拦截并提示
6. 管理员创建账号：邮箱必填、手机号选填、重复邮箱报错
7. 参赛管理筛选与详情数据与后端一致；重置教练密码后新密码可登录
8. 审计日志按模块/时间筛选，导出 CSV 可打开（含中文表头）
9. 遴选：四维评分总分 = 进球×25% + 防守×25% + 助攻×20% + 犯规×30%
10. 最佳球员未发布时前台不可见，发布后可见
