新增迁移：

```text
apps/org/migrations/0005_alter_city_province_alter_school_city_and_more.py
apps/accounts/migrations/0005_athleteprofile_uniq_athlete_team_jersey_and_more.py

```

升级步骤：

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py check
```

注意：

- 唯一约束要求现有数据中同队球衣号、球员/教练身份证不重复；空身份证会由数据迁移自动归一为 NULL，但真实的重复身份证/球衣号仍需迁移前清理。
- 身份证/球衣号唯一约束使用普通唯一索引（不再依赖 MySQL 不支持的 partial index），SQLite/MySQL 均可生效。
- 级联删除改为 `PROTECT` 后，删除被引用对象会失败并返回业务提示，这是预期行为。
- `DEBUG` 默认 False：本地开发请复制 `.env.example` 为 `.env` 并设置 `DJANGO_DEBUG=1`。

## 六、新增/变更接口速查

```text
POST   /api/auth/refresh                         刷新 access token
POST   /api/auth/password                        修改自己的密码

GET    /api/coach/profile                        教练本人资料
PUT    /api/coach/profile                        维护姓名/身份证号（实名审核前必填）
GET    /api/coach/teams                          我的球队
POST   /api/coach/teams                          创建球队（教练实名认证通过后）
GET    /api/coach/teams/{id}                     球队详情
PUT    /api/coach/teams/{id}                     修改球队（关键字段变更后重新待审）
GET    /api/coach/teams/{id}/athletes            本队球员名单
POST   /api/coach/teams/{id}/athletes            把已实名审核的球员加入本队
DELETE /api/coach/teams/{id}/athletes/{aid}      把球员移出本队

GET    /api/school/teams                         本校球队列表
POST   /api/school/teams/{id}/verify             校级审核球队（通过/驳回）
GET    /api/school/coaches                       本校教练列表
GET    /api/school/athletes                      本校球员列表

PUT    /api/registrations/{id}                   修改草稿/被驳回报名单
DELETE /api/registrations/{id}                   删除草稿/被驳回报名单
```
