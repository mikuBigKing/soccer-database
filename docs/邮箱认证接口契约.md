# 邮箱认证接口契约

统一响应：`{"code":0,"msg":"","data":...}`。
登录标识已从手机号切换为**邮箱**；手机号仍作为联系资料保留，不参与认证。

## 1. 发送验证码

`POST /api/auth/email/send`

```json
{"email": "user@example.com", "scene": "register"}
```

`scene`：`register`（注册）、`reset_password`（忘记密码）、`change_password`（已登录改密）、`change_email`（绑定/换绑邮箱）。

返回：`{"expires_in": 600, "cooldown": 60}`

规则：
- 6 位数字，10 分钟有效，用过即废
- 同邮箱同场景 60 秒冷却；每小时 5 次、每日 10 次
- 连续错 5 次需重新获取
- `register` 场景邮箱已注册 → 10001；`reset_password` 场景邮箱未注册 → 10001
- 开发环境邮件走 console 后端，验证码打印在服务端控制台

## 2. 注册

`POST /api/auth/register`

```json
{"name": "张三", "email": "user@example.com", "code": "123456",
 "password": "pass1234", "role": "athlete"}
```

`role` 仅允许 `personal` / `coach` / `athlete`。成功后直接返回 token（同登录）。

## 3. 登录

`POST /api/auth/login`

```json
{"email": "user@example.com", "password": "pass1234"}
```

- 管理员走 `/api/admin/auth/login`（字段相同）
- 手机号不再可用于登录

## 4. 已登录改密

`POST /api/auth/password`（需登录）

```json
{"old_password": "pass1234", "new_password": "newpass99", "code": "123456"}
```

验证码场景为 `change_password`。账号为占位邮箱（`@placeholder.local`）时返回 10001，提示先联系管理员补录邮箱。

## 5. 忘记密码

`POST /api/auth/password/reset`（免登录）

```json
{"email": "user@example.com", "code": "123456", "new_password": "newpass99"}
```

验证码场景为 `reset_password`。

## 6. 绑定 / 换绑邮箱

`POST /api/auth/email/change`（需登录）

```json
{"email": "new@example.com", "code": "123456"}
```

验证码场景为 `change_email`，新邮箱不能已被占用；成功后邮箱与登录名同步更新。

## 7. 存量账号说明

- 原有无邮箱账号已批量写入 `{手机号}@placeholder.local` 占位邮箱
- 占位邮箱不可收信，无法自助改密/找回；管理员通过 `PUT /api/admin/users/{id}` 补录真实邮箱后即可使用
- 后台创建账号（`POST /api/admin/users`）现在**邮箱必填**、手机号选填；球员/教练后台建档仍会自动生成占位邮箱

## 8. 前端改动点

- 登录/注册表单：手机号输入框改为邮箱，注册增加"获取验证码"按钮与 60 秒倒计时
- 改密页：增加验证码字段
- 新增忘记密码页（邮箱 + 验证码 + 新密码）
- 个人中心增加"绑定/换绑邮箱"
- 错误码：10001 参数或验证码错误、40001 发送过于频繁
